# JFIF to PNG

Conversor simples de imagens **JFIF para PNG**, feito com HTML5, CSS e JavaScript.

O projeto funciona diretamente no navegador, sem necessidade de servidor ou backend.

## Funcionalidades

- Conversão de `.jfif` para `.png`
- Processamento direto no navegador
- Drag and Drop
- Seleção de arquivos pelo explorador
- Visualização dos arquivos selecionados
- Conversão de várias imagens ao mesmo tempo
- Download de todas as imagens em um arquivo `.ZIP`
- Barra de progresso
- Interface responsiva
- Funciona em desktop e celular
- Nenhuma imagem é enviada para servidores

## Privacidade

Todo o processamento é feito localmente no navegador do usuário.

As imagens selecionadas não são enviadas para nenhum servidor externo.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Canvas API
- JSZip

## Como usar

1. Abra o site.
2. Clique na área de upload ou arraste suas imagens `.jfif`.
3. Selecione uma ou várias imagens.
4. Clique em **Converter todas e baixar ZIP**.
5. Aguarde a conversão.
6. O navegador fará o download de um arquivo contendo as imagens convertidas para PNG.
